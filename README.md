# PetStore API Automation

This is an automation project for testing the PetStore API using **RestAssured**, **TestNG**, **Java** and **Maven**.

## Technologies Used

- **Java**: Programming language.
- **Maven**: Dependency management and build tool.
- **TestNG**: Testing framework.
- **RestAssured**: API testing framework for making HTTP requests and validating responses.

## Prerequisites

- **Java 11 or later** 
- **Maven** 
- **Eclipse**

##Run Test

- Scripts are added in testng.xml file
-**Run As ->TestNG Suite**
